# Project README

## Overview
This repository contains code and documentation for experiments using eddy-covariance flux observations together with meteorological forcing and auxiliary environmental variables (e.g., vegetation, topography, and soil properties).

## Data Availability
Due to the large size of the dataset, we are unable to upload the raw data directly to this repository.

If you need access to the data, please obtain it from the original sources listed below (subject to their data-use policies and licensing terms). After downloading, you can organize the files according to the instructions in this repository (see the data preparation section / scripts, if provided).

## Data Sources
- **Flux and meteorological forcing data** were primarily obtained from the **FLUXNET2015 Tier 1** dataset:  
  https://fluxnet.org/data/fluxnet2015-dataset/

- To supplement **vegetation, topographic, and soil information** that was not fully available at individual tower sites, we incorporated auxiliary data from:  
  - **National Tibetan Plateau Data Center (TPDC)**: https://data.tpdc.ac.cn/home  
  - Other published **remote sensing products** (see references in the paper / manuscript associated with this project, if applicable).

## Notes
- Please ensure you comply with all dataset license agreements and citation requirements from FLUXNET2015 and TPDC.
- This repository provides the processing and modeling workflow; raw data redistribution is not included.

## Contact
If you have questions about data preparation or running the code, please open an issue in this repository.
